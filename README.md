# Aplikasi To-Do List

## Deskripsi
Aplikasi yang berfungsi untuk menambahan tugas, penghapusan tugas keseluruhan maupun satu persatu.

## Fitur
- Tambah tugas
- Tandai tugas selesai
- Hapus tugas (keseluruhan dan satu persatu)

## Struktur Folder
- 'index.php' - halaman utama

## Cara Menjalankan
1. Salin folder ke 'htdocs/'
2. Jalankan XAMPP dan buka di `http://localhost/todolist`
